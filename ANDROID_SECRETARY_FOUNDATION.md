## Small native slice after tools are available

1. New Android private-vault v2 service: separate Keystore alias and app-private encrypted file; AES-GCM authenticated version/revision, CAS/atomic writes, explicit session lock/unlock, foreground/background lock and encrypted preview/restore checkpoints. Match the PR2 bridge's fixed operations. No raw key, plaintext fallback, legacy migration, arbitrary file path or real credential reads. Compile and add isolated instrumentation tests for restart, tamper/key loss, locking, revision conflicts and restore before exposing the adapter to the renderer. Backups are device/key-bound, not portable recovery.
2. Confirmed native reminder delivery: start with one-shot **inexact** local notifications, explicit reminder preview/confirmation and cancellation linked to task changes. Native code rechecks consent/time and currently granted notification capability. Do not grant permission or claim exact/lock-screen/reboot guarantees; no exact-alarm permission in this first slice. Generic notification text avoids placing private task bodies on the lock screen. Unsupported/revoked notification capability leaves the existing in-app reminder path explicit. Reboot/repeating/portable scheduling needs later tests.
3. On-device-only voice adapter: use `SpeechRecognizer.createOnDeviceSpeechRecognizer` on supported Android, on the main thread, and verify installed language support before starting. Only existing microphone permission is accepted; no request, language/model download or cloud fallback. Transcript enters editable capture text and never executes an action without confirmation. Cancel on background/lock/unmount and ignore late results. API/language/service/permission gaps show typing/paste as the available path.

These steps are a proposed bounded implementation sequence, not delivered native features. Official references: [Android Keystore](https://developer.android.com/privacy-and-security/keystore), [SpeechRecognizer](https://developer.android.com/reference/android/speech/SpeechRecognizer), [alarm scheduling](https://developer.android.com/develop/background-work/services/alarms/schedule).
